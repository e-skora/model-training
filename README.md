# model-training

I am learning to fine-tune and train open AI models hands-on, and publishing every model I make.

## Models

| Model | What it does | Status |
|---|---|---|
| Memory contradiction judge | Reads two memories about a person and says whether they contradict each other, with a one-line reason | In progress |

## How it is built

- Fine-tuning with [Unsloth](https://github.com/unslothai/unsloth), on rented GPUs from [Modal](https://modal.com).
- Every model and dataset is published on [Hugging Face](https://huggingface.co/eskora).
- All training data is made up. No real personal data is used.
